# プロダクト戦略

## プロダクトの目的

**PCでの頑張りを，スマホの自由時間に変える．**

主目的は「スマホを使わせない」ことではなく，大学生や社会人がレポート執筆・研究・プログラミング・業務資料の作成など，学業や仕事のPC作業を始め，継続する動機づけ．PCでの実作業を評価して，iPhoneのスマホ利用可能時間として還元する．

## 課題と仮説

- 課題：やるべきPC作業があっても，スマホの短期的な楽しさを優先して先延ばしする．
- 仮説：**娯楽時間を事前に与えるのではなく，PCで作業して獲得する**仕組みなら，作業開始と継続の動機が高まる．
- ターゲット：PCで長時間の作業をする人．大学生に限らず社会人も対象とし，レポート執筆・研究・プログラミング・業務資料の作成など，学業と仕事の両方の作業を想定する．
- 重要な観察指標：着手までの時間，実作業時間，脱線時間，継続日数，使用感．

## 想定ユーザーストーリー

1. PCアプリ起動時のポップアップ，または招待制グループのメンバーの作業開始通知から，タスク開始画面を開く．未終了セッションがあればその画面に戻る．
2. 「レポートを書く／25分」や「業務の提案資料を作る／25分」のように作業内容・予定時間と最小作業時間を本人が設定する．
3. オンラインで作業を開始し，iPhoneへ制限適用を要求する．作業関連アプリ・サイトと放置・脱線を判別し，記録を定期送信して途中報酬を獲得する．付与条件・計算式は別途決める．
4. 小休憩では作業を一時停止し，直前までの記録送信・報酬評価後，残高内で指定した時間だけiPhoneの制限を一時解除する．対象の実利用時間で消費する．
5. オンラインで作業を再開すると利用枠の残りを破棄して再制限する．まだ利用枠に充当していない残高は同じセッション内で保持する．
6. 最小時間以上なら本人が通常終了でき，未満でも中止できる．終了・中止時は追加付与せず，全未使用報酬を破棄してスマホの制限を解除する．使用済み分は取り消さず，残高を次の作業へ持ち越さない．結果に時間内訳・根拠・獲得・利用・破棄を表示する．

作業中・一時停止中はスマホ利用を促す報酬通知を出さないが，画面で途中報酬を確認でき，グループの作業開始通知は受け取れる．登録アプリ指定／スマホ全体の制限モードを扱い，標準アプリは常時許可するがSafariはその対象外とする．開始・再開はサーバー受理後に計測でき，iPhoneの適用未確認を表示する．通信断中の終了は同期後に制限解除を進める．

グループは作成・招待・参加・退出ができ，作業開始を本人以外の現在の参加者のPCとiPhoneに通知する．個人の報酬残高をグループで共有するものではない．追加要件の導入優先度と技術的な成立条件は，要件書とPoCで整理する．

## 差別化の核

**スマホだけを制限するのではなく，デスクトップアプリの作業行動を根拠としてスマホの利用権を獲得・消費する，端末横断型の行動報酬ループ．**

「デスクトップアプリ対応」「集中スコア」「アプリブロック」は既存製品にもあるため，それだけを新規性と表現しない．
