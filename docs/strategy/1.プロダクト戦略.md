# プロダクト戦略

## プロダクトの目的

**PCでの頑張りを，スマホの自由時間に変える．**

主目的は「スマホを使わせない」ことではなく，大学生がレポート・研究・プログラミングを始め，継続する動機づけ．PCでの実作業を評価して，iPhoneのSNS・動画アプリの利用可能時間として還元する．

## 課題と仮説

- 課題：やるべきPC作業があっても，スマホの短期的な楽しさを優先して先延ばしする．
- 仮説：**娯楽時間を事前に与えるのではなく，PCで作業して獲得する**仕組みなら，作業開始と継続の動機が高まる．
- ターゲット：PCで長時間の作業をする大学生．特にレポート執筆・プログラミング・資料作成．
- 重要な観察指標：着手までの時間，実作業時間，脱線時間，継続日数，使用感．

## 想定ユーザーストーリー

1. Macで「レポートを書く／25分」と設定．
2. 作業関連アプリ・サイトと放置・脱線を判別．
3. セッション終了時に「作業18分／脱線4分／保留3分」と根拠付きで表示．
4. 獲得した時間をiPhoneの娯楽アプリの一時解除に使用．
5. 次の作業への動機につなげる．

## 差別化の核

**スマホだけを制限するのではなく，Macの作業行動を根拠としてスマホの利用権を獲得・消費する，端末横断型の行動報酬ループ．**

「Mac対応」「集中スコア」「アプリブロック」は既存製品にもあるため，それだけを新規性と表現しない．
