# 機能要件

## デスクトップアプリ

| ID   | 機能           | 要件                                                         | 優先度 |
| ---- | -------------- | ------------------------------------------------------------ | ------ |
| M-01 | ユーザー認証   | iPhoneと同じアカウントでログイン                             | 必須   |
| M-02 | タスク設定     | 作業名・作業予定時間・作業種類を設定                         | 必須   |
| M-03 | 集中タイマー   | 開始・一時停止・終了                                         | 必須   |
| M-04 | アプリ利用検出 | 最前面アプリと利用時間を取得                                 | 必須   |
| M-05 | アイドル検出   | 入力がない時間を検出し，放置を判定                           | 必須   |
| M-06 | 集中度推定     | スクロール・タイピング・アイドル・（目の動き）からスコア算出 | 必須   |
| M-07 | 報酬計算       | 有効作業時間・集中スコアから利用時間を算出                   | 必須   |
| M-08 | データ同期     | 獲得報酬をDBに保存                                           | 必須   |
| M-09 | アプリ分類     | 作業用・娯楽用・未分類を設定                                 | 必須   |
| M-10 | 作業履歴       | 過去の集中時間・報酬を表示                                   | 推奨   |
| M-11 | URL検出        | ブラウザで閲覧中のサイトを判定                               | 推奨   |
| M-12 | 作業進捗       | Word・VS Codeなどの進捗を検出                                | 発展   |
| M-13 | スクショ解析   | 画像解析によって作業状態を推定                               | 発展   |

## iosアプリ

| ID   | 機能                 | 要件                             | 優先度 |
| ---- | -------------------- | -------------------------------- | ------ |
| I-01 | ユーザー認証         | Macと同じアカウントでログイン    | 必須   |
| I-02 | スクリーンタイム認可 | ユーザー本人から制限の許可を取得 | 必須   |
| I-03 | 制限対象アプリ選択   | Instagram・YouTubeなどを選択     | 必須   |
| I-04 | アプリ制限           | 指定したアプリにShieldを表示     | 必須   |
| I-05 | 報酬同期             | Macで獲得した時間を取得          | 必須   |
| I-06 | 報酬の使用           | 獲得時間を消費して制限を解除     | 必須   |
| I-07 | 時間管理             | 解除期限と残り利用時間を管理     | 必須   |
| I-08 | 再制限               | 解除期間終了後にアプリを再制限   | 必須   |
| I-09 | 状態表示             | 制限中・解除中・残高を表示       | 必須   |
| I-11 | 利用履歴             | 過去の報酬獲得・利用履歴を表示   | 推奨   |
