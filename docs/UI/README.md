# UIモックの使い方

## 位置づけ

このディレクトリのHTMLは画面遷移・情報配置を共有するための**静的なUIモック**であり、実行アプリのフロントエンドコードではない。iOSの実装は [`mobile/`](../../mobile/README.md) にSwift / SwiftUIで作成する。Macの画面モックも同じく、実装コードとは別の参照資料である。

見た目・表示項目・画面遷移はモックを参考にする。業務上の意味や状態遷移は [`docs/spec/3.API仕様書.md`](../spec/3.API仕様書.md)、[`docs/spec/4.ドメインモデル定義.md`](../spec/4.ドメインモデル定義.md)、および要件資料を正とする。食い違いがあれば、実装者が独自に選ばず、仕様担当と確認してモックか仕様を更新する。

## 仕様と不一致が確認されている箇所

API仕様では報酬は同じ作業セッションの小休憩専用で、通常終了・中止時に未使用残高を破棄する。一方、モック08・09の一部文言は終了後にも残高を利用できるように読める。**仕様を正として実装し、該当モックの文言・遷移は更新対象として扱う。**

モック10・11の「利用枠」と「未充当残高」の区別は、画面でも分かるようにする。再開時に破棄するのは利用枠の未使用分であり、未充当残高は作業セッションが続く間は残る。セッション終了・中止時には未充当残高も破棄する。

## UIを実装に移す手順

1. 実装対象のモックと対応要件を確認する。
2. 各表示値がどのAPI・状態から来るかを整理し、未確定なら仮データとして明記する。
3. モックと業務仕様が矛盾する場合は、仕様担当と合意して資料を直してから実装する。
4. SwiftUI画面を仮データで組み、各状態（未設定・作業中・一時停止中・同期失敗など）を確認する。
5. API契約確定後にデータ供給を接続し、画面状態とサーバー状態の差を表示する。
