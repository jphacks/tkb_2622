# UIの描画で注意すること

1. 均等グリッドを避ける。2×2・3列カードの整然とした並びはAIっぽさの元。非対称レイアウト（`1.2fr:1fr` 等）を使う。比較マトリクス等、整列が意味を持つ場合のみ例外。

2. 「左線＋グレー背景カード」（`border-left` + `bg-gray`）を使わない。

3. カードUIを多用しない（最重要）。並列の複数項目（3点・Before/After 等）を、一つずつ淡い面（panel）や角丸枠の「箱」で囲んで並べない。これが最も典型的なAI生成の見た目。並列項目は箱で囲まず、項目間を細い縦罫（`1px` の `--color-corp-line`）または十分な余白だけで区切る（背景塗り・枠線の箱にしない）。淡い面／枠の箱は「1スライドに最大1つ、本当に強調したい単一ブロック（結論・主力サービス等）」に限って使う。Before/After も2枚の箱ではなく、中央の1本の縦罫で左右に分ける。

4. 箇条書きは最大3つ、間隔は広め。AIは5〜7個詰め込みがち。

5. 見出し:本文のサイズ比は 2.5:1〜3:1。 AIは 1.5:1 にしがち。階層を明確に。

6. アイコンは社内素材か Carbon Icons。絵文字・手描き風SVGは使わない。ブレットマーカーは「縦並びの箇条書き=青い丸」「横並びの項目（3点・Before/After 等）=図形なし」。横並びは見出し・余白・縦罫だけで区切る。

7. 英字の小見出し・ラベルを使わない（`SERVICE`/`PROCESS` 等のアイブロウ、`TRAINING`/`GOAL` 等）。見出しは日本語で、大見出しを主役に。意味のある英字（固有名詞・URL・番号）は可。

8. 強調にダブルクオーテーション（“…”）を使わない。また下線（`border-bottom`／アンダーライン）での強調も使わない（AIっぽさの元）。強調は強調したい文字をアクセントカラーで塗る＋太字のみ（白地=ブルー `--color-corp-blue`、青ベタ地=白文字）。引用符は実際の引用・固有表記のみ
