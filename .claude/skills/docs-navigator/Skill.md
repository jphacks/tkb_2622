# docs-navigator — 仕様の正本を探す

このリポジトリは **ドキュメント駆動**。実装より先に `docs/` の正本を確認する。`INDEX.md` が全ドキュメントの司令塔。

## 進め方

1. **まず INDEX.md を読む** — `INDEX.md` のドキュメント索引表で当たりをつける。
2. **正本を開いて該当 § を特定** — 目次から近い節へ。仕様は「正本」が1つに決まっている（下表）。
3. **重複・派生に注意** — 平易な解説版（docs/features/metrics.md）と計算式の正本（11 §7 + `constants.py`）のように、**読む用と実装の根拠が別**なことがある。実装時は必ず正本側を引く。
4. **見つからなければ**「仕様が未定」として扱い、`issue-create` の未決事項に上げるか判断を仰ぐ。憶測で実装しない。

## 出力形式

- **該当ドキュメントとリンク**（`docs/spec/13_技術仕様_バックエンドと管理画面.md §2.3` の形式で § まで。カテゴリ: 調査=research/ 戦略=strategy/ 仕様=spec/ レビュー=review/）
- **要点の3行要約**（そのまま作業に使えるレベル）
- **正本 vs 派生の注意**（実装なら根拠にすべきファイル。例: スコアは `constants.py`）
- 未決なら「仕様未定 → 判断が必要」と明記
