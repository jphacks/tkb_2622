# 仕様・設計の参照先を探す

1. リポジトリルートの `INDEX.md` を読み、対象資料を探す。
2. 該当資料の本文を確認する。索引になければ `docs/` と対象コンポーネントの README・実装を検索する。
3. 仕様と実装の現状を区別する。空ファイル、見出しだけの資料、存在しない参照先は仕様の根拠にしない。
4. 未記載の仕様は「未定」として報告する。言語・フレームワーク・クラウド・API 契約を推測で決めず、作業に必要な判断だけを利用者に確認する。

## 出力

- 実在する資料へのリンクと、記載がある場合は該当見出し。
- 今回の作業に関係する要点と、実装との相違。
- 仕様未定・資料未記入・参照切れの内容と必要な判断。

この探索だけで仕様変更や Issue 作成は行わない。
